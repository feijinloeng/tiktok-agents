# CONTEXT

## 成本公式（唯一口径）

```
广告前毛利 = 售价 − 到岸成本 − 售价 × (佣金% + 支付% + 达人佣金% + 退货% + 税%)
净利率     = (广告前毛利 − 售价 × 广告%) ÷ 售价
盈亏价     = 成本 ÷ (1 − 费率合计%)
目标价     = 成本 ÷ (1 − 费率合计% − 广告% − 目标净利%)
```

**所有百分比都按售价计**，不能当固定金额加在分子。

## 费率从哪来（重要）

| 费率 | 怎么来 |
|---|---|
| 佣金率 | **按类目不同，当场查**。脚本不设默认，必须传 `--referral-pct` |
| 支付费率 | 同上，`--payment-pct` |
| 达人佣金 | **每个达人不同，能差一倍**。不用达人填 0；用则填实际谈的 `--affiliate-pct` |
| 退货 | 默认 0；服装/鞋类建议 5–10% |
| 税 | 按你的主体与税制填，我们不预设 |

市场配置里**没有费率**。不要编一个"常见值"出来。

## SKU 四角色

```
引流款 → 拉点击、加快广告效率 → 毛利最薄（可低于目标）
主推款 → 负责成交             → 目标毛利
高配款 → 提客单价             → 更高
套装款 → 提利润               → 最高
促销（券/闪购）→ 缩小价格差距
```

**SKU 不是随便加的，是为了让买家形成对比。**
