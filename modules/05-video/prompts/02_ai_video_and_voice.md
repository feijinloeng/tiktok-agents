# PART A · 视频 Prompt（六槽位）

```
[SUBJECT]      主体：形态、颜色材质、状态
[ACTION]       动作：这一镜主体在做什么（视频区别于图片的核心）
[CAMERA]       运镜：推/拉/摇/跟/环绕/固定 + 速度
[LIGHTING]     光位与色温
[ENVIRONMENT]  背景与环境
[STYLE]        风格 + 比例 + 时长
```

三条特殊要求：

1. **动作单一** —— "同时旋转、发光、变形"会生成一团糊
2. **避免精细手部动作** —— 用手部出画/近景不露手规避
3. **运镜要慢** —— 明确写 `slow`；快运镜易位移扭曲

真人镜头：不出 Prompt，改输出拍摄指令 + 不露脸替代方案（手部/背影/远景/剪影）。

---

# PART B · 配音稿

| 规则 | 说明 |
|---|---|
| 短句 | 每句 ≤ 12 词 |
| 口语 | 写说出来的话 |
| 数字口语化 | `20000 mAh` → `twenty thousand milliamp hours` |
| 标注停顿 | 用 `|` |
| 标注重音 | 用 **加粗** |

**语速不限**（平台没规定）。给一个估算值即可，正式交付前按实际配音回听微调。

变音符号必须核对（配音念错最刺耳）：
TH 声调符号、VN 声调符号、ID 拼写。

---

# PART C · 字幕

TikTok **不限字幕字符数**，但这两条必须守：

1. **避开底部 15–20%**（平台 UI 遮挡）
2. **一屏别塞太满** —— 手机上一行超过 ~40 字符就会挤

字幕与配音**不要求逐字对应**：字幕要短，配音可以稍长。
